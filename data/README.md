# Dataset

Download `customer_support_tickets.csv` from
https://www.kaggle.com/datasets/suraj520/customer-support-ticket-dataset and place it here
(it is git-ignored, so it is not committed). Check the dataset's license on Kaggle before
redistributing any part of it.

Columns used: `Ticket Subject`, `Ticket Description`, `Ticket Type`, `Ticket Priority`.
Note: the dataset is synthetic, and its labels may not depend on the ticket text.
Notebook 01 measures this before you train with notebook 02.
